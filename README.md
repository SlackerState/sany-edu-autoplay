# 三一在线学院 · 自动连播

[edu.sany.com.cn](https://edu.sany.com.cn)（云学堂平台）学习项目的用户脚本：自动播放视频、文档自动挂满学时、完成后自动切到下一项，页面右下角带一个控制面板。

> 只做"替你点播放、替你等计时"的事：**正常倍速、不拖进度、不伪造学习记录、不碰考试**。

## 安装

1. 浏览器装一个用户脚本管理器：[脚本猫 ScriptCat](https://docs.scriptcat.org/)（推荐）或 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击下面的链接，管理器会弹出安装页面，点「安装」：

   **👉 [安装脚本](https://raw.githubusercontent.com/SlackerState/sany-edu-autoplay/main/sany-auto-play.user.js)**

   打不开 GitHub 的话试试镜像：[jsDelivr 镜像](https://cdn.jsdelivr.net/gh/SlackerState/sany-edu-autoplay@main/sany-auto-play.user.js)

3. 打开任意学习项目的课程播放页（`#/playinfo`），右下角出现面板即生效

### 在线更新

脚本头里配置了 `@updateURL`，脚本猫 / Tampermonkey 会定期检查本仓库的新版本并提示更新。也可以在管理器里手动点「检查更新」。

## 功能

| 内容类型 | 处理方式 |
| --- | --- |
| 视频 / 音频 | 自动播放到结束；暂停了会自动续播 |
| 文档 | 按平台的「还需 XX 可完成本课程学习」倒计时停留，计时满后切下一项 |
| 课程（带章节） | 先学完章节里的视频/文档，再进入下一个任务 |
| 考试、作业、调查、外链课 | **不进入**，大纲里标 ✋，最后通知你手动处理 |
| 防挂机验证 | **不代点**。暂停脚本，用响铃 + 系统通知 + 标签页标题闪烁 + 面板红色横幅提醒你 60 秒内确认；在页面上**按空格 / 回车**即可确认，不用找按钮 |

- 自动点击课程封面的「开始学习 / 继续学习」按钮，以及「我知道了 / 确定」类普通提示（考试、验证类弹窗不碰）
- 某一项长时间没有任何进度时自动跳过并通知，不会一直卡住
- 全部完成或需要手动处理时弹系统通知

### 控制面板

- 总进度、当前项（视频进度 / 文档剩余时间）
- 开始 / 停止、视频倍速、音量
- 大纲列表（✅ 已完成 / ▶ 当前 / ⬜ 待学 / ✋ 需手动），点击可直接跳转
- 运行日志
- 可拖动、可收起；位置和设置会被记住

### 设置

脚本猫里打开脚本的「设置」可以调整：进入页面是否自动开始、音量、倍速、检查间隔、切换等待时间、卡住判定时间、是否弹通知。

## 注意事项

- **不要最小化窗口**。Chrome 会暂停后台标签页里的视频，文档计时也可能暂停。可以单独开一个窗口放着，被其他窗口挡住没关系。
- 倍速建议保持 1×，加速可能不计学时。
- 默认音量 0（用音量 0 而不是静音，避免 Chrome 暂停静音视频）。
- 平台会不定时弹出**防挂机验证**，需要本人 60 秒内确认，超时本次学时清零。挂着的时候请留在电脑附近、打开声音。
- 平台改版后选择器可能失效，欢迎提 [Issue](https://github.com/SlackerState/sany-edu-autoplay/issues)。

## 开发

单文件脚本，无构建步骤。改完后**务必提升 `@version`**，否则已安装的用户收不到更新。

```bash
node --check sany-auto-play.user.js
```
